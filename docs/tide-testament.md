# 潮汐遗嘱：给尚未出生的人

这是一部可以分多晚继续的城市开放战役。暮汐城的潮水开始逆流，一名送信人失踪，而一封三十年前的信寄给了尚未出生的孩子。你来到这里，并没有被预言指定为唯一救星：船主、工匠、护理师和守闸人都会行动，你可以决定先帮助谁、怎样取得证据，以及愿意为哪一种未来承担责任。

战役包含五片可回访区域、25 处地点、25 位有各自诉求的人物、78 个可执行机会和三种需要明确选择的最终方案。另有主动撤离结局。建议把它当作一次持续旅行，预估总计 8–15 小时；阅读速度、自由行动、讨论和路线会显著改变时长，地点数量本身不保证固定游玩小时数。

## 从哪一段开始

| 篇区 | 你最先面对的问题 |
| --- | --- |
| 逆流来信 | 邮袋来自哪里？低街的人先需要什么？ |
| 盐沼证人 | 城区与盐田在同一场危机中各看见了什么？ |
| 旧闸账目 | 故障与责任怎样分开查清？ |
| 回声庭审 | 保存一个人的过去，应当由谁同意？ |
| 给后来者 | 现在能兑现哪些方案，又该给未来留什么余地？ |

“篇”是方便理解地区与议题的名字，当前不会把你锁进线性章节。地图可以提前走访，但专门工作会要求已经发现的线索。想先去最远的灯塔也可以；你不会凭抵达就自动掌握机器或结束故事。

## 建议怎样玩

第一次建议从泊灯客栈听完来信，再在找人、组织船队和查看逆流之间选一个具体问题。没有唯一正确的第一步。重要证据有替代来源，关键工作支持多项技能，整个主线可以不杀任何人完成。唯一配置的战斗也是可选办法，适配目前的一级角色规则子集；本剧本不包含自动升级、完整官方 D&D 职业进阶或网格战斗。

点选机会会先说明规则和失败后果，再由你确认掷骰。也可以自己描述合理方法：说清你要解决哪个眼前问题、凭什么这样做，比只说“我说服所有人”更容易获得可检验的裁定。已失败的同一方法不能原地重掷；新的观察、不同技能或实际准备，可以带来下一次尝试。

三只公开时钟记录抢险、检修和独立核查。行动、失败和休整会推动它们；关掉程序不会。后援可能补出线索或完成某项局部救援，这些是城里人自己的行动，会留在手记中。时钟不会替你完成灯塔最终操作，也不会替玩家选择结局。尽早介入能改变谁先得到帮助、哪些工作由你促成，以及人物对你的信任。

找到新证据后可以回访原先的人。你已经完成的救援、实际修复、发现和承诺有独立状态保存，不需要靠模型记住所有聊天。安全地点可章节休整，恢复当前规则允许的资源，同时让局势前进。每次结束游玩前，先完成或放弃已经提出的待确认行动，下一晚会更容易接续。

最后几种方案都能先做准备。准备不等于执行：修好机器、把材料谈妥、抄好档案都不会自动替整座城作决定。你必须在誓桥明确选择一种已具备前提的未来，战役才会结束。

## 怎样把角色带进来

人物可以是来自外地的学者、普通护卫、逃离家乡的信差，也可以自称失忆神明或失落王室后裔。剧本提供十处背景提问，让这些设定进入责任、名字、家族与承诺的讨论。自述不会直接变成证实的神格、领地或新能力；人物愿意认真听你，也会要求和其他人一样的证据与分工。

多人时适合让不同角色照看不同议题：一个关注居民与照护，一个核对文书，一个解释水利，一个协调共同决定。全队仍在同一地点行动，不需要有人独占“主角资格”。某个角色的个人疑问没有得到答案，也不妨碍大家先解决眼前的危机。

## 配置与验收

可执行剧本唯一权威是 [tide-testament.json](../content/worlds/tide-testament.json)。格式遵循 [持续战役规则](world-format.md) 与 [schema](../content/world.schema.json)，没有额外隐藏脚本；本文只做无剧透介绍。

维护者可运行：

```sh
node scripts/content-workflow.mjs --file content/worlds/tide-testament.json
node --test tests/long-campaign.test.mjs
```

测试使用真实移动、提案、确认和检定流程，覆盖三条非战斗通关路线、所有非结局机会的完整探索、回访、存档序列化、失败改道、时钟耗尽与明确结局选择。确定性高骰用于验证剧情依赖和结果发放，不表示真实玩家必然成功，也不能替代对节奏和趣味的实际体验。
