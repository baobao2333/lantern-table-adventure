# 灯火之下 · Windows 桌面版

下载安装包 `LanternTable-版本号-Setup.exe` 后启动，或解压便携 ZIP 后运行 `LanternTable.exe`。两种方式使用同一套程序与存档，不需要安装 Node 或 npm。

代码签名状态以发行页和 `desktop-release.json` 的 `signature.status` 为准。发行页提供 SHA-256 校验清单，供运行前核对下载文件；哈希不能代替发行者签名。维护者接入受信任证书后可通过严格签名构建链发布，配置方法见仓库 `docs/windows-signing.md`。首次发布的已签名程序也可能出现 Windows 信誉提示。

首页选择单人冒险，或多人中的创建房间／加入房间。AI 设置只由单人玩家或房主填写；加入朋友房间不需要密钥或 Codex 登录。API 连接测试可能产生服务商费用，由你主动点击后执行。

Codex 路线先点击应用内安装，程序只下载固定版本的官方 Windows CLI，并校验官方归档与执行版本；随后点击登录，在系统浏览器中完成官方登录。应用不接收 ChatGPT 密码。显示已登录仅代表凭据存在，模型当前是否可用要另行测试。

点击窗口关闭按钮会收进 Windows 托盘，服务仍在运行。右键托盘可重新打开、暂停当前房间，或选择“保存并完整退出”。完整退出先暂停并保存、取消 AI、断开连接和关闭数据库；超过 10 秒会强制停止，下次按异常退出恢复。

存档位于 `%LOCALAPPDATA%\LanternTable\desktop\adventures-desktop.sqlite`，设置位于同一 `desktop` 目录。首次升级前请关闭旧版；新版一致性备份并一次导入旧单人存档。原库保留，新版以后不自动合并旧版产生的变化。不要同时继续旧版与新版中的同一冒险。

更新和普通卸载保留存档与本机配置。清理数据应在完整退出后由你单独决定。私有备份可能含权限和凭据摘要，不应作为分享文件发送给朋友；不要分享 `settings.json`、Codex 登录文件或整个数据目录。

公网多人是否可连接取决于双方网络条件。安装包不代表任意网络都能直连；连接失败时按页面提示使用备用入口或更换房主。具体已验证的网络范围以该版本发布说明为准。

桌面与服务加载随包提供的本地页面；不加载邀请指定的远程 HTML。第三方许可与版本清单位于 `resources\runtime`。应用源码的公开不等于授予自由使用许可，具体版权状态见随包 `LICENSE`；Electron／Chromium／Node 的许可随包保留。Codex CLI 采用 Apache-2.0，来源与固定版本记录在 `codex-release.json`，认证文件不在发行包中。
